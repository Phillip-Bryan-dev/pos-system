# POS System

A web-based Point of Sale (POS) system designed for small businesses to manage products, inventory, sales, and basic reporting.

## Problem

Small businesses need a reliable way to record sales, track stock levels, and understand their daily performance. This project aims to build a simple, maintainable system that supports those workflows.

## Project Goals

- Practise full-stack software engineering.
- Build a responsive and accessible user interface.
- Design a relational database and REST API.
- Apply validation, testing, and secure development practices.
- Deploy a working application and document its architecture.

## Planned Features

- [ ] Product and category management
- [ ] Inventory and stock tracking
- [ ] Shopping cart and sales processing
- [ ] Sales history and receipts
- [ ] Daily sales summaries
- [ ] User authentication and roles
- [ ] Automated tests

## Planned Technology

- Frontend: React and TypeScript
- Backend: Node.js, Express, and TypeScript
- Database: PostgreSQL
- Version control: Git and GitHub

## Development Roadmap

1. Establish the project and interface.
2. Implement product and inventory management.
3. Build the sales workflow and database.
4. Add validation, tests, and authentication.
5. Deploy the MVP and document how it works.

## Status

Early development. Features will be implemented incrementally as the project progresses.
